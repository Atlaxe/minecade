# Shared blocks pack

Custom blocks that maps can use. The build adds this pack to every server (the lobby, every game
and the map editor), the same way it adds the core resource pack, so any server can load a map
that uses these blocks.

- `behavior_pack/`: the block definitions (`manifest.json`, `blocks/`, and so on), two invisible
  entities (a stool's seat and a chest's storage), and a script that gives the blocks their
  placement rules, neighbor connections and right-click actions.
- `resource_pack/`: their textures, models and names.

Each half is used only once it has a `manifest.json` and some content, so this slot can stay empty.

Both folders are generated by the private block-pack project (`tools/generate.py`, then
`tools/install_bedrock.py`, which copies them here) and are git-ignored: they hold textures and
models from other people's mods, used with permission for this private network only. Never commit
them, and never add other textures here.

Maps that use the blocks are built in Java (with the project's Fabric mod) and converted to Bedrock
with Chunker and the project's block mappings (`block_mappings.chunker.json`). The map editor never
maps blocks: it only prunes Bedrock worlds to Bedrock, and Chunker keeps blocks it doesn't
recognize.
